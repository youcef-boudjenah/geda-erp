Déploiement Simplifié

Comment installer et activer GEDA ERP en 4 étapes

Aucun terminal compliqué ni configuration obscure. L'installateur Windows et l'assistant de configuration embarqué prennent tout en charge.

Étape 01

Télécharger le Setup

Téléchargez l'installateur officiel Windows GEDA_ERP_v2.5_Setup.exe. Tout est inclus (serveur, moteur de base de données, bibliothèques).

Télécharger l'EXE (85.6 Mo)
Étape 02

Lancer l'Installation

Exécutez le fichier d'installation. Dès le premier lancement, l'assistant vous invite à choisir votre base (SQLite ou MySQL) et à créer votre compte administrateur.

0 donnée démo · Base propre pour votre société
Étape 03

Copier votre Identifiant (HWID)

Sur l'écran d'activation (/license/activate/), copiez votre code matériel machine unique (ex: GEDA-4222-1F4A-F889-F252).

Protection matérielle Node-Locked
Étape 04

Recevoir votre Clé d'Activation

Transmettez votre identifiant à GEDA Solution par WhatsApp ou téléphone. Vous recevez immédiatement votre clé numérique signée pour débloquer votre ERP.
